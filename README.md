# AbstractClassesMedicalPortal

Практическая работа по C# на тему **«Абстрактные классы в C#»**.

## Описание программы

Консольная программа моделирует простой медицинский портал. В ней есть абстрактный класс `Doctor` и его наследники — `Therapist`, `Cardiologist`, `Dentist` и `Neurologist`. Для пациентов создаётся запись на приём (`Appointment`), после чего программа выводит информацию о пациенте, враче, дате приёма и действиях специалиста.

## Используемые элементы ООП

- абстрактный класс `Doctor`;
- наследование (классы врачей наследуются от `Doctor`);
- абстрактные методы (`Reception()`);
- переопределение методов и свойств через `override`;
- конструкторы и вызов конструктора базового класса через `base`;
- полиморфизм (объекты врачей хранятся в переменных типа `Doctor`);
- абстрактное свойство `Specialization`.

## Запуск

Требуется установленный .NET SDK 8.0 или новее.

```bash
dotnet run
```

Или по шагам:

```bash
dotnet build
dotnet run
```
